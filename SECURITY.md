# Security Policy

## Scope

This project is intended for authorized recovery and incident-response work. Do not use it to bypass authentication, defeat encryption, evade access controls, or inspect data without authorization.

## Reporting a vulnerability

Do not disclose sensitive evidence, credentials, recovery codes, or customer data in a public issue. Report security defects privately to the repository maintainers with the affected version, operating system, reproduction steps, and a minimal non-sensitive sample.

## Operational requirements

Run from a trusted host, preserve original evidence, prefer read-only sources or forensic images, use encrypted case storage, and restrict service endpoints to authenticated operators. Review every plugin before installation. Keep the CLI and native dependencies patched.
